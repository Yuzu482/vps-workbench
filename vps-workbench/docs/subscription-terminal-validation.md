# Claude Code 订阅终端离线验收

## 输出布局和批处理

基线为 `0e2551a`。在 Windows 11 x64 上用 Edge 158.0.4370.33 的隔离预览重跑两组各三次。每轮发送同一结构的 512 行、34,260 字节夹具，切为 128 或 10 个合法事件。单事件最大 3,426 字节。计时从浏览器收到第一批轮询响应起，到 xterm 的渲染行出现尾标记为止。帧间隔来自同期的 `requestAnimationFrame`，采样持续到尾行出现后 250 ms。

| 事件数 | 轮次 | 基线尾行 ms | 修复后尾行 ms | 基线帧间隔 p50 / p95 / 最大 ms | 修复后帧间隔 p50 / p95 / 最大 ms |
|---:|---:|---:|---:|---:|---:|
| 128 | 1 | 998.5 | 27.3 | 6.1 / 6.2 / 18.3 | 6.1 / 6.2 / 6.2 |
| 128 | 2 | 988.2 | 15.2 | 6.1 / 6.2 / 6.4 | 6.1 / 6.2 / 6.4 |
| 128 | 3 | 971.3 | 16.4 | 6.1 / 6.2 / 6.2 | 6.1 / 6.2 / 6.2 |
| 10 | 1 | 91.1 | 14.2 | 6.1 / 6.6 / 12.1 | 6.1 / 6.1 / 6.2 |
| 10 | 2 | 44.1 | 9.2 | 6.1 / 6.2 / 6.2 | 6.1 / 6.1 / 6.2 |
| 10 | 3 | 37.9 | 9.2 | 6.1 / 6.2 / 6.2 | 6.1 / 6.1 / 6.2 |

两组均校验输出尾部的顺序、字符与轮询回执。128 个事件按 64、64 读取，10 个事件一批读取。12 轮采样的帧间隔均在 33 ms 内。复跑基准可从仓库根目录执行 `node --test --test-name-pattern 'burst benchmark' vps-workbench/terminal/subscription-preview.test.mjs`。

| 预览窗口 | xterm 列 × 行 | 卡片内宽 px | 行内容宽 px |
|---|---:|---:|---:|
| 365×480 | 36×4 | 333 | 297 |
| 420×640 | 43×13 | 386 | 355 |
| 1280×720 | 84×17 | 728 | 693 |

三个窗口均验证跟随时尾行与提示符可见、输入与状态可达，且回看历史时追加输出保留当前首行。测试还覆盖跨轮询页的 UTF-8 字节、拆分的 ANSI 序列、无效页不推进回执、查询原连接、会话错配及关闭后的尾部回执。

现有 `native-resize` 复用固定 Dev.14 桥的会话鉴权，返回的是本地管道写入结果。固定归档中的 Linux helper 会把收到的 SSH 窗口尺寸应用到内层 PTY。Windows x64 候选包的离线回归和真实 SSH 的内层 PTY 尺寸、全屏程序重绘、输入法是各自独立的验收项。
